# NeoBank — Full Stack Banking Application

A full stack banking app built with Spring Boot + React.

## Projects
- `/banking-system` — Spring Boot backend (Java 17, Spring Security, JWT, MySQL)
- `/banking-ui` — React frontend (React 18, Tailwind CSS, Vite)

## Features
- JWT Authentication
- Account Management (Savings / Current)
- Deposit / Withdraw / Transfer
- Transaction History with Pagination
- AI Spending Insights
- Dark / Light Mode
- Razorpay Payment Gateway (coming soon)
